# Phantom user guide

Phantom is a hardware identity privacy tool for machines you own or are
expressly authorized to test. It is not for evading fraud controls or
misrepresenting a device you do not control.

Start here. These pages walk from install to first profile to the
details.

## Getting started

1. [Install](install.md): download, verify, and install the MSI.
2. [Your first profile](first-profile.md): generate, apply, validate,
   and revert. Free tier is enough to start.

## Licensing

- [Licensing](licensing.md): the Free, Pro, and Enterprise tiers, how
  keys are issued, and how they bind to one machine.
- [Activate your license](activate.md): activate a Pro or Enterprise
  key.

## Privacy and cleanup

- [Privacy and phone-home](privacy.md): what Phantom sends, when, and
  how to keep it off (it is off by default).
- [Uninstall](uninstall.md): the uninstall reverts every applied
  identifier before removing the files.

## Reference

- `phantom --help` lists every command.
- `phantom privacy-notice` and `phantom tou` print the Privacy Notice
  and Terms of Use.
- The top-level [README](../../README.md) has the full CLI reference and
  the exact set of registry identifiers Layer 2 changes.
